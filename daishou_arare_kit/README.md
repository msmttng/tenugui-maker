# 仲羽田（江戸角字）＆ 大小あられ 配置 — 統合システム一式の説明

手ぬぐい用の**「仲羽田（羽・田・仲 江戸角字）」**（元データの6箇所の幾何学的ズレを完全修正したパラメトリック格子）と**「大小あられ」**柄をマージした統合デザイン・入稿データ作成システムです。
文字の色・背景の色・サイズ・繰り返し密度・線の細さ（太さ）・文字内の抜け幅・縦横間隔・傾き角度・丸紋「仲はねだ」を自在に変更し、Illustrator でそのまま使える **SVG / .ai (CMYKレイヤー分け) / .jsx / 300dpi PNG** に書き出せます。

---

## 1. ファイル一覧

| ファイル | 種類 | 内容 |
|---|---|---|
| `arare_app.html` | アプリ本体（完成品） | ダブルクリックでブラウザが開き、そのまま使える統合アプリ（仲羽田＋大小あられ＋丸紋） |
| `app_template.html` | アプリのソース | 画面・処理のすべて（HTML/CSS/JavaScript）。`/*__LIB__*/` と `/*__EMBLEM__*/` に形状データを埋め込む |
| `arare_shapes.json` | データ | 大小あられの粒形状データ 160 個と直径一覧 |
| `emblem_vector.json` | データ | 丸紋「仲はねだ」をベクター化した閉曲線ループ群（法線オフセットにより太さ変更対応） |
| `build_app.py` | ビルド | `app_template.html` + `arare_shapes.json` + `emblem_vector.json` → `arare_app.html` と `arare_app_artifact.html` |
| `arare_trace.py` | 変換スクリプト | 元画像から粒をベクター化し、手ぬぐいサイズに継ぎ足して SVG / PDF / .ai / .jsx を作る |

## 3. 書き出し機能

- **SVGをコピー（Illustratorに貼り付け）**: クリップボードへ実寸mmのSVGをコピー。Illustratorで「編集 → ペースト」するとそのまま実寸ベクターとして貼り付きます。
- **SVGで保存**: `tenugui_<mode>_<幅>x<丈>.svg`（レイヤーグループ `Background_Navy`, `Arare_Dots`, `HanedaNaka_Kakuji`, `Nakahaneda_Crest`）。
- **.ai を保存**: Illustrator 8 形式（CMYK・レイヤー分け済み）。クリッピングマスクに依存せず、布端で正確にポリゴン切断された純粋なパスとして出力するため、どのバージョンの Illustrator でも崩れずに開けます。
- **.jsx (AIスクリプト)**: Illustrator の「ファイル → スクリプト」から実行して日本語レイヤー付きCMYKドキュメントを自動生成。
- **300dpi PNG保存**: 印刷入稿・プレビュー確認用の高解像度（300dpi）PNG出力。
